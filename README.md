# Site Nath que fez

Site institucional da Nath que fez. Página única (`index.html`), sem build.

- Publicado no Netlify. Por enquanto vai ao ar só a página `em-breve/` (ver `netlify.toml`).
- `nathquefez.com.br/cardapio` mostra o cardápio, que fica no repositório [PEDIDOS](https://github.com/NathQueFez/PEDIDOS).
- No lançamento: em `netlify.toml`, troque `publish = "em-breve"` por `publish = "."` e tire o `X-Robots-Tag`.
